# yeonmukwan_site
site web de l'école Yeon Mu Kwan

## Note JS
- customElements.define(nom, classe) — natif. C'est LA fonction qui enregistre ta balise auprès du navigateur.
- extends HTMLElement — natif. Ta classe hérite du comportement de base de tout élément HTML.
- connectedCallback() — natif. C'est une méthode que le navigateur appelle automatiquement dès que ta balise est insérée dans le DOM. Tu ne l'appelles jamais toi-même.
